# SisaBaik - Frontend Vue.js

Proyek frontend SisaBaik (Chapter 9).

## Perintah Running
- Install paket: `npm install`
- Mode dev: `npm run dev` (http://127.0.0.1:5173/)
- Build & preview: `npm run build` lanjut `npm run preview` (http://127.0.0.1:4173/)

## Catatan
- Memakai Node.js versi v22.22.0
- Gambar dan ikon berbasis SVG di folder `src/assets`.
- Data penawaran masih pakai data lokal di memori (fixture), belum terhubung ke API backend. Integrasi API dilakukan di pertemuan 11.
